## 1. هيكل المشروع (Project Structure)

تم بناء المشروع بالكامل باستخدام تقنيات الويب القياسية (**HTML5, CSS3, Vanilla JavaScript**) بدون أي مكتبات أو أطر عمل ثقيلة وبدون الحاجة إلى خادم خلفي، مما يجعله جاهزاً للعمل مباشرة على **GitHub Pages** أو أي استضافة ثابتة:

```text
├── index.html       # الهيكل البنائي الدلالي باللغة العربية (RTL) مع كافة الأقسام والنوافذ المنبثقة
├── styles.css       # نظام التنسيقات الفاخر (Dark Streetwear)، المتجاوب بالكامل مع الشاشات
├── products.js      # قاعدة البيانات الأولية لـ 14 منتجاً تغطي كافة الأقسام الثمانية وألوان وخامات المتجر
├── app.js           # المحرك البرمجي التفاعلي: استوديو التصميم، السلة، إتمام طلبات الواتساب، ولوحة الإدارة
└── README.md        # دليل التثبيت، والتشغيل، والإعداد، والنشر على GitHub Pages
```

## 2. كيفية تشغيل المشروع محلياً (How to Run Locally)

### الطريقة الأولى: التشغيل المباشر
1. قم بتحميل أو فك ضغط ملفات المشروع.
2. انقر نقراً مزدوجاً على ملف `index.html` ليفتح في أي متصفح ويب حديث (Google Chrome, Firefox, Safari, Microsoft Edge).
3. سيعمل المتجر بكافة وظائفه دون الحاجة لتثبيت أي برامج!

### الطريقة الثانية: باستخدام سيرفر محلي (Live Server)
إذا كنت تستخدم محرر أكواد مثل **Visual Studio Code**:
1. ثبّت إضافة **Live Server**.
2. اضغط بيمين الفأرة على ملف `index.html` واختر **Open with Live Server**.
3. سيفتح المتجر على الرابط: `http://localhost:5500` أو المنفذ المحدد.

## 3. كيفية ضبط رقم الواتساب الخاص بالمتجر (Configuring WhatsApp Number)

مالك المتجر هو **كريم السيد**. لتوجيه رسائل الطلبات إلى هاتفك الحقيقي مباشرة:

### من خلال واجهة المتجر (بدون تعديل كود):
1. اضغط على زر **"الإدارة"** في شريط التنقل العلوي.
2. انتقل إلى تبويب **"إعدادات المتجر وواتساب"**.
3. أدخل رقم هاتفك بصيغة الأرقام الدولية بدون أصفار في البداية وبدون رمز `+`.
   * مثال في مصر: إذا كان رقمك `01012345678`، أدخله هكذا: `201012345678`.
4. اضغط على **"حفظ الإعدادات"**.

### من خلال الكود المصدري:
افتح ملف `products.js`، وستجد في السطر 26 كائن الإعدادات:
```javascript
const DEFAULT_SETTINGS = {
  storeName: 'كريم السيد | KARIM ELSAYED',
  whatsappNumber: '201012345678', // ضع رقم هاتفك هنا مع كود الدولة
  defaultDeliveryFee: 50,
  currency: 'ج.م'
};
```

## 4. كيفية إدارة المنتجات وتغيير الأسعار (Managing Products & Prices)

جميع أسعار وبيانات المنتجات مستمدة من قاعدة البيانات المحلية وليست نصوصاً ثابتة عشوائية:

1. **تعديل الأسعار والمخزون:**
   - افتح لوحة **"الإدارة"** أعلى الصفحة.
   - في جدول المنتجات، اضغط على زر **"تعديل"** بجانب أي قطعة.
   - قم بتغيير السعر، أو سعر الخصم (Sale Price)، أو الكمية المتوفرة بالمخزون.
   - اضغط **"حفظ المنتج في المتجر"**.

2. **إضافة منتج جديد:**
   - من لوحة الإدارة، اختر تبويب **"إضافة منتج جديد"**.
   - املأ اسم المنتج، التصنيف (من التصنيفات الـ 8 المعتمدة)، السعر، المقاسات، والألوان.
   - يمكنك رفع صورة من جهازك، وسيقوم المتصفح بضغطها وحفظها محلياً.

3. **استعادة المنتجات الأصلية:**
   - عند الحاجة لإلغاء التعديلات والعودة للبيانات النموذجية الأصلية، اضغط على زر **"استعادة المنتجات الافتراضية"** من لوحة الإدارة.

## 5. كيفية استخدام استوديو طباعة التيشيرتات المخصص (Custom T-Shirt Designer)

استوديو التصميم هو إحدى أهم الميزات الحصرية في متجر كريم السيد:
1. انزل إلى قسم **"استوديو التصميم المخصص"** (أو اضغط على زر "استوديو التصميم" في القائمة).
2. اختر لون التيشيرت المفضل من لوحة الألوان (أسود فحمي، أبيض، رمادي، بيج، كحلي، زيتي).
3. اختر موضع الطباعة: **الوجه الأمامي** أو **الوجه الخلفي**.
4. اضغط على منطقة الرفع أو اسحب صورتك (JPG, PNG, WEBP) إليها.
5. **التحكم بالتصميم:**
   - **التحريك:** اسحب الصورة بإصبعك على شاشات اللمس أو بالماوس داخل حدود منطقة الطباعة المحددة.
   - **الحجم:** استخدم شريط التكبير والتصغير (Slider) لضبط مقاس الطبعة.
   - **المحاذاة:** استخدم أزرار التوسيط الأفقي والرأسي للمحاذاة التلقائية.
6. اختر مقاس التيشيرت المطلوب (S حتى 3XL).
7. اضغط على زر **"إضافة التيشيرت للسلة"**.
8. **ملاحظة:** يمكن للعميل تصميم أكثر من تيشيرت بتصاميم وصور وألوان مختلفة وجمعها كلها في نفس السلة!

## 6. كيفية إتمام الطلب عبر واتساب (WhatsApp Order Flow)

1. بعد إضافة القطع أو التيشيرتات المخصصة للسلة، افتح السلة واضغط **"متابعة الطلب عبر واتساب"**.
2. تفتح نافذة إدخال بيانات الشحن:
   - الاسم بالكامل
   - رقم الهاتف
   - المحافظة (يتم تعديل قيمة الشحن تلقائياً حسب المحافظة)
   - العنوان التفصيلي
   - ملاحظات إضافية
3. يعرض المتجر **معاينة حية فورية** لنص الرسالة العربية المنظمة بوضوح تام.
4. بالضغط على **"تأكيد وإرسال الطلب عبر واتساب"**، يُفتح تطبيق واتساب على محادثة المتجر مع نص الرسالة الكامل جاهزاً للإرسال.
5. **تنبيه مهم للتصاميم المخصصة:** نظراً للقيود الأمنية في متصفحات الإنترنت وبروتوكول `wa.me`، لا يمكن إرفاق ملف صورة مخزن على جهاز العميل تلقائياً داخل رابط؛ لذا تم توضيح ذلك للعميل في واجهة المتجر ورسالة الطلب، حيث يُطلب منه إرسال الصورة الأصلية التي استخدمها في التصميم مباشرة داخل شات الواتساب للحصول على أعلى دقة طباعة.

## 7. النشر على استضافة GitHub Pages (Publishing on GitHub Pages)

المشروع مصمم ليعمل على **GitHub Pages** بنسبة 100% بدون أي إعدادات بناء معقدة:
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub باسم مثل `karim-elsayed-store`.
2. ارفع الملفات الخمسة (`index.html`, `styles.css`, `app.js`, `products.js`, `README.md`) إلى الفرع الرئيسي `main`.
3. انتقل إلى إعدادات المستودع **Settings** -> ثم تبويب **Pages**.
4. تحت قسم **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: اختر **main** والمسار **/ (root)**.
5. اضغط **Save**، وخلال دقيقة واحدة سيكون متجرك متاحاً أونلاين على رابط مثل:
   `https://<your-username>.github.io/karim-elsayed-store/`

## 8. القيود التقنية المعروفة ولماذا يلزم وجود Backend لمتجر تجاري كامل؟ (Known Limitations)

1. **نطاق التخزين المحلي (localStorage Scope):**
   - التعديلات التي تجريها في لوحة الإدارة وسلة المشتريات تُحفظ في **المتصفح الحالي لجهازك فقط**.
   - لا تنتقل هذه التعديلات إلى أجهزة العملاء الآخرين، لأن هذا التطبيق يعمل كواجهة أمامية بحتة (Client-Side Only) تلبيةً لمتطلبات العمل المجاني على GitHub Pages بدون خوادم مدفوعة.

2. **الترقية للاستخدام التجاري الواسع (Production Readiness):**
   - لفتح متجر تجاري متكامل تدار فيه المخازن وتستقبل فيه المدفوعات البنكية آلياً عبر البطاقات، يُنصح بربط هذه الواجهة بخادم خلفي (Node.js/Express أو Python) وقاعدة بيانات سحابية (مثل PostgreSQL أو Firebase Firestore)، ونظام مصادقة للمدراء (Authentication) وبوابة دفع معتمدة (مثل Paymob أو Fawry).
